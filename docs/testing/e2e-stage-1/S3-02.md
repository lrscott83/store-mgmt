## User Story

Como OwnerAdmin, quiero dar de alta empleados en mi tienda, para que operen la caja con su propia cuenta.

## Precondiciones

- OwnerAdmin autenticado con feature `Users` (`user-create.tsx:11`).
- `selectedStoreId` no vacío, o `:storeId` en la ruta.

## Flujo

1. Ir a `/management/users` y presionar "crear", o llegar a `/management/users/create/:storeId` tras crear una tienda.
2. Completar el formulario y enviar.

## Aserciones — Playwright (UI)

- [x] El payload incluye **siempre** `roleIds: [3]` (`ERoles.StoreUser`), *hardcodeado* — no hay selector de rol en la pantalla (`user-create.tsx:49`; `enums/index.ts:4`). Verificado en `e2e/create-store-user.spec.ts`.
- [x] El `storeId` del payload resuelve como `paramStoreId ?? user.selectedStoreId` (`user-create.tsx:20,43`). Verificado en `e2e/create-store-user.spec.ts`.
- [ ] Sin `storeId` resoluble, la pantalla **redirige** a `/management/stores` y no renderiza nada (`user-create.tsx:25-29,59-61`). — Brecha declarada: requiere un OwnerAdmin sin selectedStoreId, inalcanzable vía la UI normal.
- [x] Offline: el botón guardar está deshabilitado (`UserCreateForm.tsx:73`). Verificado en `e2e/create-store-user.spec.ts`.
- [x] Éxito → navega a `/management/users` (`user-create.tsx:51`). Verificado en `e2e/create-store-user.spec.ts`.
- [ ] Fallo → muestra `USERS.ERROR` y permanece en la pantalla (`user-create.tsx:52-53`). — Brecha declarada: requiere forzar un error del backend (500).
- [x] Un StoreUser en esta ruta es deslogueado y redirigido a `/login` (`adminFeatureLoader` → `adminLoader` — `loaders.ts:101-103`). Ver **H-8**. Verificado en `e2e/create-store-user.spec.ts`.
