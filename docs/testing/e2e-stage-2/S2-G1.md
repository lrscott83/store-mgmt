## Descripción

Como OwnerAdmin, quiero exportar todos los datos de la app (productos, ventas, créditos, inventario, gastos) a un archivo ZIP cifrado, para crear un respaldo o transferir datos a otro dispositivo.

## Flujo

1. Ir a `/sync/export`
2. Ingresar contraseña maestra
3. Confirmar exportación
4. Se descarga un archivo `.smcabundle`

## Aserciones — vitest (ya existentes)

- [x] `serializeData` produce un ZIP con una entrada por dominio
- [x] Cada entrada está cifrada con AES-GCM
- [x] La contraseña del ZIP es `${master}${storeId}`
- [x] Round-trip: deserialize(serialize(data)) == data

## Aserciones — Playwright (cubiertas)

- [x] La exportación descarga un archivo ZIP (`datosYYMMDD-HHMM.zip`)
- [x] El archivo empieza con la firma ZIP `PK\x03\x04`
- [x] Contraseña vacía muestra error sin descargar
- [x] La exportación funciona en modo offline
