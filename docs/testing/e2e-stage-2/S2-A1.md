## Descripción

Como usuario (OwnerAdmin o StoreUser), quiero crear, editar y eliminar productos desde la UI, para mantener el catálogo actualizado sin depender de la conexión a internet.

## Aserciones — vitest (ya existentes)

- [x] `createProduct` persiste el producto en localStorage con cifrado AES-GCM
- [x] `updateProduct` modifica campos existentes
- [x] `deleteProduct` elimina el producto
- [x] `getProductsByCategory` filtra por categoría
- [x] Round-trip de cifrado: serialize → deserialize mantiene la integridad

## Aserciones — Playwright (CUBIERTO)

- [x] Crear un producto nuevo desde la UI aparece en la lista de la categoría
- [x] Editar un producto modifica nombre y precio
- [x] Desactivar un producto lo marca como inactivo (badge)
- [x] Crear producto sin nombre muestra error de validación
- [x] La operación funciona correctamente en modo offline
- [x] Los datos persisten tras recargar la página
- [ ] Crear producto con precio 0 o negativo muestra error (requiere cambio en el form validation)
- [ ] Eliminar un producto lo remueve de la lista (soft delete → desactivar, ya cubierto arriba)

## Nota

La mayoría de la lógica CRUD ya está cubierta por vitest. Los tests Playwright se enfocan en la **interacción del usuario** con los formularios y la **verificación visual** de que los datos aparecen en la UI.
