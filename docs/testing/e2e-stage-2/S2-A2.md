# S2-A2 — CRUD offline de categorías

> **Prioridad**: CRÍTICA
> **Estado Playwright**: ✅ CUBIERTO
> **Spec**: `e2e/category-crud.spec.ts` (5 tests, 5 aserciones)

## Aerciones Playwright

| # | Test | Qué verifica |
|---|---|---|
| 1 | Crear categoría nueva aparece en la lista | Abre modal → llena nombre → submit → categoría visible |
| 2 | Editar categoría modifica el nombre | Crea → gear menu → "Categoría" → cambia nombre → submit → nombre nuevo visible |
| 3 | Crear sin nombre muestra error | Modal abierto → submit vacío → "Nombre es requerido" |
| 4 | Offline funciona | setOffline → crea categoría → aparece en localStorage |
| 5 | Persistencia tras recargar | Crea → reload → categoría sigue ahí |

## Hallazgos durante implementación

- El modal de categorías usa los mismos `data-testid` que el de productos: `category-name-input`, `category-order-input`, `category-save-button`.
- El gear menu de categoría se accede con `data-testid="category-actions-toggle-{id}"` y la acción de editar con `data-testid="edit-category-button"`.
- Cada test restaura el snapshot pre-sigma, así que las categorías creadas en test N no existen en test N+1 — cada test crea la suya inline.
