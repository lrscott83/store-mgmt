## Descripción

Como OwnerAdmin, quiero importar datos desde un archivo `.smcabundle` exportado, para restaurar un respaldo o recibir datos de otro dispositivo.

## Flujo

1. Ir a `/sync/import`
2. Seleccionar archivo `.smcabundle`
3. Ingresar contraseña maestra
4. Confirmar importación
5. Los datos se mergean con los existentes

## Aserciones — vitest (ya existentes)

- [x] `deserializeData` extrae las entradas del ZIP cifrado
- [x] Contraseña incorrecta produce `WrongPasswordError`
- [x] Archivo corrupto produce `CorruptFileError`
- [x] `synchronizeData` mergea correctamente datos nuevos con existentes

## Aserciones — Playwright (cubiertas)
